# 这是什么，不是什么

一句话：**这是一个把关键帧变成动效的排版工具，不是 AI 视频生成器。**

它更接近 PPT 动画或 After Effects 的简化版：AI 只负责画 3–8 张关键帧，
中间的运动交给数学。知道这一点，后面的取舍就都能解释。

## 三个关键设计

**1. 以「拍」为单位，不以「帧」为单位。**
创作单位是 3–8 个关键帧，不是 24/60 张连续画面。这决定了成本：24 帧只花 3 次采样，
不是优化出来的，是定义出来的。

**2. 插值，而不是逐帧重绘。**
逐帧 img2img 能补细节，但每帧都要重编码，误差会累积。实测（512²、8 步、24 帧）：

| | 逐帧重绘 | 关键帧插值 |
| --- | --- | --- |
| 采样次数 | 24 | 3 |
| 墙钟 | 40.1 s | 15.5 s |
| 漂移曲线 | 0 → 38 一路爬升 | 峰值 16 → 末帧 1.5，闭合 |

一个是随机游走，一个是闭环。表情包、贴纸、短循环要的是后者。

**3. APNG 是主产物，GIF 只是兼容。**
APNG 逐帧无损、真彩 + alpha；GIF 256 色、会合并相同帧、时长按 10ms 取整。
自检先看 APNG，GIF 只确认能播。

## 它擅长什么

不是电影镜头，是**有节奏的短循环**：表情包、角色贴纸、微故事三连拍、商品展示、
UI 动效、二创梗图。这些内容的共同点是——观众看的是「变化」，不是「运动」。

## 它的天花板

- 中间帧是**形变**，不是表演：手不会真的抬起来，只会从 A 平滑过渡到 B。
- 镜头是 2D 仿射，没有视差；推近不会「走进场景」。
- 画质上限由关键帧决定，插值只会让它更顺，不会让它更好。
- 它替代不了视频模型，也不该去比。

## 什么时候别用它

| 你要的效果 | 该用什么 |
| --- | --- |
| 真实的人物动作、口型、走路 | 视频模型（Wan / MiniMax H3 等） |
| 3D 视差、环绕、推轨 | 3D 预演工具 + 视频模型 |
| 每帧都要生成新细节的变形 | 逐帧 img2img / Deforum 类 |
| 长镜头、多场景剪辑 | 时间轴工具 + 视频模型 |
| **一张图会动、能循环、能对拍** | **本项目** |

## 为什么轻量不是妥协

12GB 笔记本显卡就能跑，不加新模型、不加新依赖，所有运动可复现（同 seed 同参数同结果），
所有参数可解释（位移多少像素、缩放多少倍、缓动哪一档）。

代价是控制粒度粗：只有 3–8 拍、一个 2D 镜头、一条曲线。但在这个粒度上，
它能做到「改一个数字，整段重来一遍还是不漂」——这是重方案反而难保证的。
